# رفّ

موقع لتتبّع الألعاب والأفلام والمسلسلات والأنمي: سجّل اللي لعبته وشفته، قيّمه، اكتب مراجعات، سوّ قوائم، وتابع أصدقاءك.

- **الألعاب** من [IGDB](https://www.igdb.com) (نفس مصدر Backloggd) أو [RAWG](https://rawg.io)، و**الأفلام والمسلسلات والأنمي** من [TMDB](https://www.themoviedb.org)، مع البوسترات الحقيقية.
- حسابات وتسجيل دخول، ولكل عضو صفحة عامة على `/u/<اسم المستخدم>`.
- مكتبة بست حالات، تقييم بنص نجمة، مراجعات (مع إخفاء الحرق)، مفضلة (5 لكل نوع + تاج 👑)، وقوائم مرتّبة.
- متابعة الأعضاء، ونشاط اللي تتابعهم، ولايكات وتعليقات على المراجعات، ولايكات على القوائم، وصفحة لايكات (اللي جتك واللي عطيتها)، وتنبيهات.
- يشتغل على الجوال والكمبيوتر، وتقدر تضيفه للشاشة الرئيسية كتطبيق.

**طريقة التشغيل والنشر: [SETUP.md](SETUP.md)**

## البنية
| المجلد | المحتوى |
|---|---|
| `index.html`, `src/` | الواجهة (Vite + JavaScript بدون إطار). `src/original.css` هو تصميم النسخة الأصلية كما هو |
| `src/pages/` | الصفحات: الرئيسية، الملف، العمل، المراجعة، القائمة، استكشف، البحث، الأعضاء، التنبيهات، الإعدادات، النقل |
| `api/` | دوال Vercel اللي تكلّم RAWG/TMDB بالمفاتيح السرّية وتحفظ بيانات العمل في القاعدة |
| `supabase/schema.sql` | الجداول وصلاحيات الحماية (RLS) والعدّادات |
| `src/legacy.json`, `legacy/` | بيانات وملف النسخة القديمة، للنقل لمرة وحدة |
